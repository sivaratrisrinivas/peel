# Persist metadata, not recovered content

Logs and SQLite may contain Run IDs, state transitions, mechanism types, locations, counts, hashes, durations, error codes, and approval metadata. Workbook values, Reveal Samples, draft bodies, credentials, app passwords, attachment bytes, and email contents are excluded. TrueForge presents ephemeral Reveal, Repair Plan, and Verification cards, while only the separately bound approval events authorize Repair or Disclosure.
