# Send email is a direct approval-gated tool

`send_email` will be invoked only as a direct MCP tool explicitly named in TrueForge's approval policy, never through Code Mode. Repair Approval and Disclosure Approval are separate decisions: one complete Repair Plan is approved and applied atomically to a new artifact, denying Repair leaves the original untouched, and denying a Disclosure Attempt causes zero SMTP activity. No mutation is automatic: even a Repair classified safe and recommended remains in the plan and requires Repair Approval. A later Disclosure Attempt against the same verified artifact requires a fresh native approval and a distinct idempotency key. The mailbox server will restrict recipients to owned demo mailboxes and reject duplicate successful attempts so that TrueForge provides the visible human stop while the server limits damage from misconfiguration or duplicate invocation.
