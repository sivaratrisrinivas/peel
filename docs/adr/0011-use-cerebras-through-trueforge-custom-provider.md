# Use Cerebras through the TrueForge custom provider

TrueForge will use Cerebras Inference through its custom OpenAI-compatible provider with base URL `https://api.cerebras.ai/v1` and model `gpt-oss-120b`. The Cerebras key remains in TrueForge's local secret configuration and is never committed. Tool calls execute serially with `parallel_tool_calls: false`. Because this model rejects requests that combine `tools` with `response_format`, tool-running turns will not request structured response formatting; any deterministic presentation formatting occurs in a separate tool-free turn or in application code. Strict schemas set `additionalProperties: false` at every object level. The environment go/no must prove a multi-turn tool call, a denied native approval, and the chosen Generative UI path against Cerebras before product implementation. If `gpt-oss-120b` fails that exact spike, the only MVP fallback is Cerebras `qwen-3-32b` under the same constraints; failure of both is surfaced rather than silently changing provider or weakening approval.
