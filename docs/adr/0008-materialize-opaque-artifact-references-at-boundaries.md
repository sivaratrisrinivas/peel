# Materialize opaque artifact references at boundaries

Mailbox attachments and repaired workbooks will cross systems as opaque authenticated Artifact References, not assumed shared filesystem paths. The orchestration adapter will explicitly download or stream the mailbox attachment to a local temporary file, upload it to Daytona, retrieve only a declared TrueForge sandbox artifact, and materialize it for the direct SMTP tool. The MVP accepts exactly one `.xlsx` attachment no larger than 10 MiB and compares the artifact's SHA-256 at each materialization boundary. Embedded base64 is reserved for proven-small artifacts. A hash mismatch, expired reference, incomplete transfer, or unproven adapter limit fails closed. Adapter-specific reference lifetimes, attachment schemas, and size limits must pass the environment go/no before product implementation.
